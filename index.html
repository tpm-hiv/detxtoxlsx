What changed since the first version

The first version converted a DETX into an Excel workbook. Since then:

  • Exports to Excel, RTF, Word, SRT and TTML — TTML in an EZTitle or a Youdub profile
  • New Cast sheet in the workbook: each role, a blank column for the actor, and its line count
  • Workbook columns reordered to TC in, TC out, Character, Original, Translated
  • Pick one or more roles and export only their lines, in any format — Excel can also give each role its own sheet
  • Search the transcript for a word or a name; roles who never say it are dimmed, so you can see who does
  • Live preview of the export beside the transcript, updating as you change format, roles or options
  • Frame rate read from the file's timecodes when you load it
  • Role sex written as F / M / N in the dubbing scripts
  • Programme poster and title looked up from the filename when you drop a file
